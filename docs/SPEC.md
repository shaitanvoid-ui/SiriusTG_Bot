# ПОЛНЫЙ ФУНКЦИОНАЛ

## Юзерская часть
- /start с многоуровневой капчей (эмодзи-картинка, что нажать — на картинке, не текстом).
- Принятие пользовательского соглашения при первом входе.
- Проверка подписки на обязательных спонсоров (public + private channels). Для private — invite link (с возможностью авто-генерации персональных через createChatInviteLink).
- Главное меню: Кликер, Рефералы, Задания, Вывод, Промокод, Бонус, Колесо, Топ, Достижения, Профиль, История, Поддержка, Инструкция, Канал, Отзыв.

## Кликер
- 0.01⭐ за клик, лимит 100/день (настраивается в админке).
- Минимальный интервал между кликами >250мс.
- Мини-капча каждые 20-30 кликов (1 эмодзи — что лишнее).
- Бонусы к кликам по уровню юзера.

## Рефералы (1 уровень)
- 3⭐ за реферала после подписки на ВСЕ обязательные спонсоры.
- Если реф отписался — звёзды списываются у реферера (счётчик рефов НЕ уменьшается, реф остаётся навсегда).
- Если подписался обратно — звёзды возвращаются.
- Через 7 дней реф "созревает" — звёзды зафиксированы.
- **Лимита на приглашения нет.** Мультиаккаунты разрешены: проектные цели — гнать подписки в каналы спонсоров, лимиты будут лишь резать выручку.
- Долг (debt) если списание ушло в минус.
- Реферальные материалы: готовые тексты, картинки, статистика по UTM.

## Задания (опциональные спонсоры)
- Подписка на канал / переход по ссылке / запуск бота.
- Награда настраивается на каждое.
- Лимит подписок на спонсора (когда заполнено — авто-выкл).

## Промокоды
- Код, награда ⭐, макс. активаций, срок действия.
- Honeypot-промокоды (нигде не публикуются → кто ввёл = бан).

## Ежедневный бонус
- 0.5⭐ если в bio юзера стоит его рефка (проверка через Telethon).
- Streak: 1 день — 0.5⭐, 3 дня — 0.7⭐, 7 дней — 1⭐, 14 дней — 1.5⭐, 30+ дней — 2⭐.
- Сброс при пропуске дня.

## Колесо фортуны
- 1 бесплатное вращение/день.
- Платное вращение: 1⭐ за попытку, призы 0.5-5⭐ (матожидание <1⭐).
- Призы: 0.01 / 0.05 / 0.1 / 0.5 / 1⭐ / "пусто".

## Уровни (5 уровней)
- Бронза (старт): x1 клик, лимит 100/день.
- Серебро (5 рефов): x1.1, 120/день.
- Золото (15 рефов): x1.25, 150/день.
- Платина (50 рефов): x1.5, 200/день.
- Алмаз (150 рефов): x2, 300/день.
- Прогресс-бар в профиле.

## Лидерборд
- Топ-100 по рефералам / неделя / месяц / всё время.
- Минимум 10 подтверждённых рефов для попадания.
- Авто-награды топ-10 раз в неделю (1: 50⭐, 2: 30⭐, 3: 20⭐, 4-10: 5⭐).

## Достижения
- "Пригласи 10/50/100", "Накликай 1000⭐", "Заходи 7 дней подряд" и т.п.
- Единоразовая ⭐ за каждое.

## Вывод подарков (через Telethon userbot)
- Метод: payments.sendStarsForm + inputInvoiceStarGiftResale (внутреннее имя метода, **в пользовательских текстах не упоминать**; для юзера — «официальные подарки Telegram через бота»). Юзер получает подарок от userbot — может оставить или продать.
- Условия: ≥5 рефов, баланс ≥ цена подарка, прошёл капчу, не shadow-banned.
- Минимум 15⭐. Максимум 5 выводов/сутки на юзера.
- Витрина подарков: динамически через getAvailableGifts, фильтры (Дешёвые/Топ/Эксклюзив), сортировка.
- Очередь выводов (pending → processing → done/failed/retry). При нехватке ⭐ у userbot — waitlist с показом позиции.
- Idempotency (юзер не может создать дубль).
- Rate limit 3-10 сек + jitter между отправками.
- Failover: main userbot → backup userbot → ручной режим.
- История выводов у юзера.

## Поддержка
- Юзер пишет в том же боте через раздел "💬 Поддержка".
- FAQ перед написанием (снимает большинство вопросов).
- Тикеты: статусы (новый / в работе / ждёт ответа / закрыт).
- Ты отвечаешь из админки → бот пересылает юзеру.
- Автозакрытие через 7 дней без ответа.
- Антиспам: >3 тикетов/час — автоответ.

## Инструкция
- Раздел "📖 Инструкция" в главном меню.
- Подробная пошаговая инструкция по разделам:
  как заработать звёзды, как вывести, как поднять уровень и попасть в топ, ежедневный бонус, FAQ.
- Контент хранится в БД, редактируется через админку без правки кода.
- Разбита на разделы с навигацией (Назад/Далее).

## Канал бота
- Кнопка "📢 Наш канал" в главном меню — внешняя ссылка (URL хранится в settings).
- Канал автоматически добавлен как обязательный спонсор (с возможностью отключить в админке).
- В канал админ выкладывает: промокоды, новости, акции, объявления.

## Отзывы (отдельный канал отзывов)
- Раздел "💝 Оставить отзыв" в главном меню.
- FSM-flow: выбор рейтинга (1-5⭐) → текст отзыва → выбор анонимности (с username или анонимно) → подтверждение.
- 4-уровневая защита:
  1. Авто-фильтры: длина 30-500 символов, без ссылок, без капса >30%, без мата (стоп-слова из БД, редактируются), без 3+ одинаковых эмодзи подряд.
  2. Антиспам: 1 отзыв в 7 дней, минимум 3 реферала у юзера, не shadow-banned.
  3. Ручная модерация админом из админки.
  4. Форматирование при публикации в канал отзывов.
- Низкие оценки (1-2⭐) НЕ публикуются в канал даже после модерации — админу предлагается превратить в тикет поддержки.
- Формат публикации: рейтинг звёздами + текст + (@username или "Анонимный пользователь") + дата + ссылка на бота (общая или реферальная автора — выбирается в settings).
- Награда за опубликованный отзыв (настраивается, по умолчанию 1⭐, можно отключить).
- ID канала отзывов хранится в settings.
- Статистика рейтинга в дашборде админки (средний рейтинг, распределение по звёздам).
- Жалобы (кнопка отдельно от отзыва) уходят в поддержку, не в канал.

- Можно включать/выключать в профиле.

# АНТИФРОД

- Многоуровневая капча (эмодзи на картинке + математика для подозрительных).
- Проверка возраста аккаунта через Telethon (минимум — настраивается в админке).

- ML-скоринг (правила с весами): возраст аккаунта, username, темп рефералов, паттерн кликов, общий риск-score. >70 баллов — shadow-ban.
- Honeypot-промокоды.
- Honeypot-задание (фейковый канал — кто "выполнил" не подписавшись — бан).
- Shadow-ban (юзер видит бот как обычно, награды не начисляются).
- Sub-rechecker воркер каждые 6 часов на случайной выборке.
- Все действия пишутся в action_logs для аналитики.
- Глобальный rate-limit middleware (20 действий/мин на юзера).

# ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
